# 🌐 Portfólio Pessoal

Um site de portfólio pessoal moderno e responsivo, desenvolvido para apresentar meus projetos, habilidades e trajetória profissional de forma clara e acessível. Conta também com uma seção de contato direta para facilitar novas conexões.

---

## 🚀 Funcionalidades

- **Design Responsivo:** Adaptado para navegação fluida em dispositivos móveis, tablets e desktops.
- **Seção de Projetos:** Exposição dos meus principais trabalhos com links diretos e descrições.
- **Sobre Mim & Habilidades:** Visão geral da minha trajetória e tecnologias que utilizo no dia a dia.
- **Formulário de Contato:** Interface para envio de mensagens diretas de recrutadores e visitantes.
- **Navegação Interativa:** Efeitos de rolagem suave e menu adaptável.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout flexível (Flexbox/Grid), animações e responsividade.
- **JavaScript (ES6+):** Manipulação do DOM, validações e interatividade da interface.
